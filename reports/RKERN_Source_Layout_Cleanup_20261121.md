# RKern 소스 구조 정리 보고서

아이템 리팩토링 브랜치의 커밋 `467a494`를 기준으로 작업했다.

## 완료한 작업

- **이름과 패키지.** RKern Java 소스에서 기존 `MJ`·`NC` 명칭이 들어간 패키지, 클래스와 구현 주석을 정리했다. 아이템 조립·강화·표기·발동, 캐릭터 스킬, NPC 동작, 아레나와 던전, 공통 도구를 담당 영역에 배치했다. `Combat`과 `combat` 경로를 통합해 대소문자를 구분하지 않는 환경에서도 경로가 겹치지 않게 했다.
- **참조와 import.** 옮긴 클래스의 import, 완전한 클래스 이름과 빌드·검증 스크립트 경로를 함께 수정했다. 아이템 조립의 `CItem`과 `CItemEnchantOption`에 빠진 `L1PcInstance` import를 추가했다. 변경된 파일의 import 순서를 정리하고 불필요한 import를 제거했다.
- **미사용·중복 코드.** 소스와 확인한 설정에서 호출 경로가 없던 아이템 교환 핸들러 20개와 공통 헬퍼 13개를 삭제했다. 구현이 같은 레이드 스킬 세 클래스를 `AttackSkill`로 통합했다.
- **기존 설정 호환.** 레이드 스킬과 인스턴스 로비의 이전 클래스 이름을 새 구현으로 해석한다. 기존 DB에 저장된 이름을 받을 수 있도록 호환 매핑에 해당 문자열을 유지했다. 소스의 저작자·라이선스 표기도 유지했다.

## 검증

- Java 21 전체 프로덕션 소스 컴파일을 통과했다. 기존 폐기 예정 API 경고 5건이 남아 있다.
- 로비의 이전 전체 클래스 이름과 레이드의 이전 짧은 이름·전체 이름으로 새 구현을 불러오는 스모크 테스트를 통과했다.

## 남은 작업

- 운영 DB와 설정 파일을 붙여 기존 클래스 이름을 쓰는 로비·레이드·GM 명령과 실제 서버 시작 경로를 확인한다.
- 로그인, 아이템 장착·강화·표기, NPC, 아레나와 던전 흐름을 실제 클라이언트에서 검증한다.
- 설정이나 외부 스크립트가 호출할 수 있어 보류한 클래스는 운영 참조가 확인된 뒤 정리한다. 패키지 이동으로 경로가 바뀐 과거 검증 스크립트는 현재 기준에서 다시 실행한다.
