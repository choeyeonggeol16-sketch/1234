# 맨손·속성 저항 구현 및 중복 감사 결과

기준: 기존 통합본 `67d82d0`. 요청 보고서: main의 `a35ee43`에 추가된 `RKern_Lineage1_JP_Unarmed_ElementalResistance_Verification_20261112.md`. 소스 Java 10개를 변경했고, 이전 IOCP·스레드풀·마법·물리·HP/MP 및 재점검 보완을 모두 유지합니다.

## 확인한 결함과 수정

1. **맨손이 일반 무기 계산을 통과했습니다.** `CAttackAction.AttackTargetData.calcPcPcDamage/calcPcNpcDamage`에서 무기 스냅샷이 없으면 명중 후 1/2만 추첨하도록 분기했습니다. STR·장비/인형 추가타·공격 버프·크리티컬·대상 DR 계산을 우회합니다. `calcHit`의 기존 명중 확률은 유지하며 확정 명중으로 바꾸지 않았습니다.
2. **최종 수신 단계에서도 맨손 피해가 변할 수 있었습니다.** 공격 시점의 맨손 여부를 기존 CCreatureController의 피해 종류 값으로 전달합니다. 기존 링과 기존 overflow에 같은 태그가 보존됩니다. `L1PcInstance`는 이 태그일 때만 루시퍼 감면·변신 PvP 추가타·기본 PvP DR·장비 발동 DR의 수치 반영을 제외합니다. 장비 발동 콜백의 다른 부수효과, 위협/독/반격/상태 이상·일반 무적 규칙은 기존 경로를 유지합니다. 무기를 들지 않은 시전자의 일반 마법에는 이 태그가 붙지 않습니다. 신규 큐·워커·병렬 피해 계산기는 없습니다.
3. **활 전용 변신의 맨손 공격을 차단했습니다.** 기존 polymorphs의 무기 허용 마스크가 활 전용인 경우 패킷/자동공격 진입, 명중, 피해, 모션 경로에서 거부합니다. 모르는 스프라이트와 활/근접 겸용 마스크는 임의로 차단하지 않습니다. 하드코딩한 변신 ID는 없습니다.
4. **실제 저항 스탯 중복 차감: NPC 폴다운 재시전.** `RecastPolicy`에서 `ELEMENTAL_FALL_DOWN`은 일반 시간 갱신의 예외입니다. 이후 `SkillHandlers.onElementalFallDown`의 PC 분기는 기존 효과를 제거하지만 몬스터 분기는 이를 하지 않아, 같은 화속성 -50을 다시 걸면 -100이 됐습니다. 몬스터도 기존 효과의 `SkillStopHandlers.offElementalFallDown`을 먼저 실행하여 이전 채널을 되돌린 뒤 새 채널 -50을 적용하도록 고쳤습니다. 화→수 변경·효과 종료도 원복됩니다.
5. **속성 상한·음수·정수 계산을 보완했습니다.** 물리 무기 추가타는 기존 `L1WeaponAttrEnchantHelper`가 `long` 정수 곱셈/100과 FLOOR를 소유하도록 정리했습니다. 기존 단계별 1/3/5/7/9, 특수 화살 +3, NPC 약점 -50 정책은 유지합니다. 양의 저항만 100에서 제한하고 음수는 보존합니다. `SpellDamageFormula`의 -100 하한을 제거하여 -128 등도 손실되지 않습니다. 일반 마법은 INT 계수 안의 속성 처리를 유지하므로 저항100이라고 무조건 0이 되지 않습니다.
6. **남아 있던 구식 경로의 실제 산술 오류도 수정했습니다.** `L1Magic.calcAttrResistance`의 정수 `resistFloor / 100` 때문에 저항40에서 0이 반환됐습니다. 기존 45% 곡선은 유지하면서 0.18이 반환되도록 고치고 100 상한을 적용했습니다. 같은 클래스의 채널 조회 복제는 `targetElementResist`로 정리했습니다. 방화벽의 별도 고정 방어식은 유지합니다. `L1WeaponSkill.calcDamageReduction`과 `MJCommons.getAttrDamage`도 100 이후 음수 피해가 나오거나 추가 감면되지 않도록 상한을 적용했습니다. MJ의 기존 설정 가중치는 바꾸지 않았습니다.

**동일 피해 성분의 이중 속성 감면은 위 호출 체인에서 발견하지 못했습니다. 발견한 실제 중복은 NPC 폴다운의 저항 스탯 중복 차감이며 제거했습니다.** `research/resistance-calls.txt`는 수정 전 전체 src의 관련 호출 검색 기록입니다. 장비 기본 저항(`L1EquipmentSlot`)과 세트 보너스(`L1ArmorSet`)는 서로 다른 효과입니다. 인형·요리·잠재력의 독립 효과도 유지했습니다. RESIST_ELEMENT 패시브는 getter의 +5 한 곳에서 계산되고 패시브 등록부는 알림만 하므로 별도의 +5 중복 가산을 찾지 못했습니다. 일반 RESIST_ELEMENTAL은 재시전 정책이 시간만 갱신하고, 로그인 복원 레지스트리는 별도 복원 경로입니다. 실제 장비 착탈/버프 동시 경합 전체를 라이브 검증했다는 의미는 아닙니다.

## 재현 및 회귀 결과

- 수정 전: 맨손 피해가 DR 등 일반 식에 들어가 0이 됨, NPC 폴다운 재시전 -100, 구식 저항40에서 계수0을 각각 재현했습니다. `logs/element-before.log` 참고.
- 수정 후: 실제 PC/PC 및 PC/NPC 맨손 1/2, STR127·큰 추가타·버프·DR, 기존 명중의 실패, 실제 PC HP 전달, 무기를 들지 않은 시전자의 마법 유지, 놓친 공격 미전달을 확인했습니다.
- 기존 링이 포화된 상태에서 맨손 피해81개가 태그와 정확한 HP를 보존했습니다. bow-only 변신은 명중/피해/모션 진입을 막고 혼합 마스크는 허용했습니다.
- 무기 속성 20단계/4채널 × 저항 -128/-100/-20/0/19/20/21/40/60/79/80/81/90/99/100/101/110/130 = 360조건의 정수 결과와 기존 NPC 매핑을 확인했습니다. 실제 Resistance 저장 범위는 -128~127이며 130 입력은 저장 상한으로 정규화됩니다. 순수 함수의 130 상한도 별도 검사했습니다.
- 기본100+속성9/저항40의 전체 물리 경로 결과105, 채널별 getter1회, 최종 수신 단계에서 재감면 없음, 독립 효과 합산/제거를 확인했습니다. 현재 무기 인챈트 스냅샷은 단일 채널이며 다중 발동 성분 전체의 라이브 조합 실험을 주장하지 않습니다.
- 실제 NPC 스킬 핸들러·재시전 예외·종료 콜백에서 같은 채널 재시전 -50, 채널 변경 후 이전0/새 채널-50, 종료 후0을 확인했습니다. 테스트는 효과 시간 등록을 대역으로 수행하고 시각 패킷만 제외합니다.
- Java 1,696개 전체 타입 컴파일: 오류0 / 기존 API 제거 예정 경고5개. 기존 마법 수식·중첩/overflow·물리 피해·HP/MP·H2 저장·스초/저장 잠금 회귀도 통과했습니다. ZIP CRC·전 바이트·이전 통합본에 diff 적용 검증도 통과했습니다.

## 적용과 남은 실측

ZIP은 src/만 들어 있으며 이전 수정을 전부 포함합니다. **새 SQL은 없습니다. 기존 HP/MP 패치의 `RKern_HPMP_GROWTH_20261112.sql`은 여전히 필요하며 이미 적용했다면 다시 실행하지 않습니다.** 기존 라이브러리와 UTF-8/Java21 및 FFM 옵션으로 재빌드합니다.

**U07의 일본 특수 1피해 NPC는 현재 source-only 묶음에서 실제 운영 DB의 NPC ID를 확정할 수 없어 임의 매핑을 추가하지 않았습니다.** 기존 NPC 수신/반격/무적 등 특수 경로를 보존합니다. 활 전용 판정은 실제 운영 polymorphs의 허용 마스크 데이터에 의존합니다. 일본 2015 관찰이 2019 한국 운영에 그대로 적용된다고 증명한 것은 아닙니다.

Windows 실게임·운영 DB·실제 맵/변신 데이터·모든 주문/무기 발동 조합·운영 부하는 미검증입니다. 테스트는 연결하지 않은 PC, 로컬 H2의 변신 테이블, NPC 월드/HP 전달 대역 및 시각 패킷 대역을 사용합니다. 운영 DB에는 접속하지 않았습니다. 경고 로그의 설정 파일 부재는 시험 환경의 기본값 사용이며 운영 설정 파일은 수정하지 않았습니다.
