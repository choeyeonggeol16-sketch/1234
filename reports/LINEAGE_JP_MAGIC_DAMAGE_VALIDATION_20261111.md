# 일본 리니지1 마법 데미지 연구 실측표 vs 복원식 — 수치 재현 검증

- 검증일: **2026-11-11**
- 대상: 일본 연구진의 2016년 잠정 마법 데미지 공식과 공개된 측정표
- 상태: **연구 자료 내 재현 검증 완료 / 독립 본서버 검증 아님**
- 주의: **RKern 운영 서버 코드와의 실행 결과 비교가 아니다.** RKern 소스에 새 공식을 적용했다는 의미도 아니다.

## 1. 자료와 비교 목적

- [일본 실측 데이터 원본 — 魔法ダメージ 公開用, `計測結果` 탭](https://docs.google.com/spreadsheets/d/1SThgf5q83PMDphjq6oAFzyONxVnOlvh2IGDc5T3YYEY/edit#gid=2120210286)
- [기존 마법 공식·속성저항 결합 및 RKern 구현 명세](./LINEAGE_JP_MAGIC_DAMAGE_2016_FORMULA_IMPLEMENTATION_20261111.md)

목적은 연구진이 공개한 측정 데미지를 **동일한 입력값으로 일본식 복원 공식에서 다시 산출**하여 정수 단위 일치율과 오차를 계산하는 것이다. 여기서 “복원식”은 일본 실측 자료로부터 연구진이 도출한 잠정식에 기반한다. 따라서 **학습·도출에 사용된 자료에 대한 재현율(in-sample fit)**이지 독립적인 정확도 검증이 아니다.

## 2. 비교에 사용한 공식

```text
A = floor_0.01(1 + (3/32) * (INT + SP - ML - MB - 12))
C = defenderClassCoefficient - 0.02 * floor(defenderWIS / 2)
B = floor_0.01(C * (defenderMR - attackerMH)^(-0.3))

normal = floor(floor(Dice * A) * B) + MD - DR
critical = floor(floor(floor(Dice * A) * 1.5) * B) + MD - DR
```

- `floor_0.01(x)`는 양수 범위에서 소수 둘째 자리까지 내림.
- **방어자 클래스 계수**: PRI 2.30, KNI 2.40, ELF 2.20, WIZ 2.00, DE 2.20, DRK 2.40, ILL 2.20, WAR 2.40.
- `DR`가 빈 입력 칸인 경우 0으로 취급.
- **MR−MH ≥ 10**인 측정 조건만 포함했다. MR−MH < 10은 이 잠정식의 적용이 미확정이므로 제외했다.
- **속성저항 ER은 이번 측정 데이터의 독립 변수로 주어지지 않으므로 비교하지 않았다.** 2015년 ER 식과 2016년 MR 식을 결합한 후보 전체에 대한 검증 결과로 해석하면 안 된다.
- 시트의 계산 결과 차이 열을 통계의 정답으로 사용한 것이 아니라, 측정 데미지 칸을 읽어 공식으로 재계산하여 비교했다.

## 8. 구현 단계에서 남은 검증

1. **저MR 경계**: MR−MH=9와 10의 연결을 임의 보정하지 말고 별도의 본서버 측정값으로 검증.
2. **속성저항**: ER=0/25/50/75/100과 INT/SP별 측정 세트를 모아 ER 차감 단계와 절삭 위치 검증.
3. **크리티컬 예외**: 행 121·192 같은 3~6데미지 차이 조건을 조사하여 계수/크리티컬 처리/자료 입력 상태 확인.
4. **B 계수 경계**: 일부 행에서 재계산한 B와 시트의 채택 B가 다르다. 예: 행 27(0.51 대 0.52), 534(0.93 대 0.89), 570(0.75 대 0.70), 826(0.76 대 0.74). 수작업 선택 계수와 원 식은 구분해야 한다.
5. **인게임 비교**: 독립적으로 확보한 동일 환경의 본서버 결과와 재현 코드 결과를 대조하여 out-of-sample 재현율 측정.

## 9. 해석

이 데이터에서 **일본 2016년 연구식에 기반한 계산의 실측표 재현율은 98.75%**이다. **±1데미지 허용 시 99.78%**이다. 이는 연구진이 발표한 계산 구조가 당시 실측표를 매우 잘 설명한다는 정량적 근거다.

그러나 (1) 연구식의 출처 데이터와 평가 데이터가 같고, (2) 속성저항 변수가 별도 검증되지 않았으며, (3) MR−MH < 10은 제외됐고, (4) 실제 RKern 서버에 적용·인게임 검증하지 않았다. 그러므로 **현대 본서버 전체 마법이 98.75% 동일하다**거나 **속성저항 통합식까지 그 수치로 검증됐다**고 해석하지 않는다.
