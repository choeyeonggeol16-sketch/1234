# MJBin PSS: BotPlayPath / pathfind / A* 정적 분석 메모

대상: `mjlin.bin` (PE32 x86, ImageBase `0x00400000`)과 실행 메모리 이미지 `mjlin_loaded_code_00400000_0180D000.bin`.
분석 형태: 정적 x86 기계어 대조. 실행 후킹·실제 게임 클라이언트 동작 검증은 수행하지 않았다. 아래 주소는 VA이며 복호화 메모리 이미지 기준이다.

## 개별 구성 요소

| 위치 | 정적 관찰 | 판단 |
|---|---|---|
| `0x00669B20` | `BotConductor::Next` 행동 진행기 | 행동 판단/실행 담당 |
| `0x0067F000` | `BotPlayPath` 행동 노드 진입 | PSS 경로 항목 실행 |
| `0x0075EDB0` | 현재 인덱스 증가, 리스트 끝이면 `-1` 기록 | 경로 항목 반복/순차 접근 |
| `0x0075F040` | `0..4` 항목 유형에 따른 점프 테이블 | PATH/TELEPORT/DIALOG/HACTION/ITEM 분기 |
| `0x00F08D60` | `pathfind` 명령 처리기 | 길찾기 활성화/비활성화 제어 |
| `0x00A31D90` | `mov al,[ecx+0x5BC]`; `ret` | 경로 사용 플래그 조회 |
| `0x00A330D0` | `mov [ecx+0x5BC],al`; `ret 4` | 같은 플래그 갱신 |
| `0x00B9E200` | 관련 경로/이동 처리 함수 진입 | 정확한 상위·하위 호출망은 별도 확인 필요 |
| `0x00ECEC10` | 격자 기반 경로 탐색 함수 진입 | A* 계열 탐색 평가 코드 포함 |
| `0x00EC7A40`, `0x00EC79B0` | 탐색 후보 노드 `[+0x14]` 비교를 이용한 힙 처리 | 최소 f 점수 선호에 부합 |
| `0x00ECF0F9..0x00ECF129` | 목적지 거리·깊이를 가중 합산하고 음수로 점수 저장 | A* 비용 평가 증거 |

## A* 비용 평가에서 직접 확인한 명령

```asm
0x00ECF0F9  imul ecx, dword ptr [ecx], 0x3e8
0x00ECF0FF  add ecx, eax
0x00ECF104  inc eax
0x00ECF10C  mov [esi+0xc], eax
0x00ECF10F  imul eax, eax, 0x3e8
0x00ECF115  mov [esi+0x10], ecx
0x00ECF118  neg ecx
0x00ECF123  sub ecx, eax
0x00ECF129  mov [esi+0x14], ecx
```

거리 차이를 이용한 휴리스틱 비용과 부모 깊이(누적 탐색 단계)에 기반한 이동 비용을 결합한다. 우선순위 값은 음수로 저장되며, 후보 힙이 해당 필드로 정렬된다. 따라서 **A* 계열의 f=g+h 평가**로 해석할 근거가 강하다. 원본 데이터 구조의 모든 필드 의미, 비용 가중치의 모든 경계·타일 장애물 반영, 재경로 계산 전체 흐름까지 확정한 것은 아니다.

## PSS의 길찾기와 경로 재생 구분

- **행동 두뇌**: `BotConductor`와 각각의 `Bot*Node`; 무엇을 할지 결정.
- **경로 항목 재생**: `BotPlayPath`; `PathInfo.PathType`의 `PATH=0, TELEPORT=1, DIALOG=2, HACTION=3, ITEM=4`로 다양한 작업을 진행.
- **길찾기 ON/OFF**: `CommandUsePathFinding`; 길찾기 기능 플래그를 켜고 끔. 알고리즘 자체가 아님.
- **격자 경로 탐색**: `0x00ECEC10` 등. 실제 움직임의 경로 후보 계산 담당.

이전에 기록한 PSS 시작 `0x0066A0BA` / 종료 `0x00668B83` 플래그 변경, `0x00BA0601` 설정 참조는 후속 호출망 검증 대상으로 유지한다. 단일 디스어셈블리 증거만으로 이 모든 주소가 항상 같은 실행 경로에서 호출된다고 단정하지 않는다.

## 미확인

- PSS JSON 단계 연결 그래프와 정확한 노드별 실패 전이
- 동적 NPC/PC 타일 점유의 A* 비용·통행 반영 방식
- A* 힙의 모든 종료 조건 및 우회 실패 정책
- 실제 사용 클라이언트에서 PSS와 `pathfind` 토글의 상호작용
