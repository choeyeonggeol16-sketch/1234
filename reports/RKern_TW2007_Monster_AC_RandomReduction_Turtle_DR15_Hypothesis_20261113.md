# RKern 리니지1 — 대만 AC 랜덤 피해감소와 일본 지저호 거북이 DR 15 교차 검증

- 작성: 2026-11-13
- 범위: **PC 리니지1의 몬스터가 받는 물리 피해 감소**. 마법 성공 확률, 변신, 플레이어 공격 배율은 다루지 않는다.
- 판정: **AC 기반 랜덤 감소는 유력한 검증 가설이지만 몬스터에게 직접 확증된 공식은 아니다.**
- 상태: 외부 원문 수치 교차 확인; **RKern 코드 미수정·몬스터 인게임 실험 미실시**.

## 1. 대만 2007년의 9,045회 실험: 정확히 무엇을 측정했나?

2007-09-15 대만 바하무트의 殘暴的哈士奇(sungies) 원문: [寵物的防禦與怪物的攻擊力](https://forum.gamer.com.tw/Co.php?bsn=00842&sn=3143591).

실험 버전은 戰與和 260C. 공격자는 오렌 지역에서 테이밍한 **레벨 15 오우거**이고, 방어자는 **레벨 6 고급 도베르만**이다. 별도로 레벨 53 요정 AC +10을 대조군으로 공격했다.

| 방어자 | 최종 AC | 타격 수 | 관측 피해 범위 | 평균 피해 | 연구자의 추정 랜덤 감소 |
|---|---:|---:|---|---:|---|
| 도베르만, 방어구 없음 | +10 | 1,123 | 7~19 | 12.96 | 0 |
| 도베르만, 펫 가죽갑옷(-4) | +6 | 2,147 | 5~19 | 12.04 | 0~2 |
| 도베르만, 펫 뼈갑옷(-7) | +3 | 4,364 | 4~19 | 11.50 | 0~3 |
| 도베르만, 펫 십자갑옷(-13) | -3 | 1,411 | 2~17 | 10.27 | 0~6 |
| **펫 소계** | | **9,045** | | | |
| 대조군: 요정, 방어구 등 상태 고정 | +10 | 1,436 | 7~19 | 13.07 | 0 |
| **전체 관측** | | **10,481** | | | |

**주의 — 기존 구두 설명의 정정:** 최종 AC -3 조건의 관측 최고 피해는 **17**이지 19가 아니다. 19가 관측되지 않았다는 사실만으로 원래 최고 피해 19가 불가능하다고 결론 낼 수는 없지만, '모든 조건에서 19가 관측됐다'고 쓰면 틀리다.

피해 평균은 AC +10에서 12.96, AC +6에서 12.04(차이 0.92), AC +3에서 11.50(차이 1.46), AC -3에서 10.27(차이 2.69)이다. 표본이 큰 조건에서 매 타격마다 **0~상한의 난수 감소**와 대체로 부합한다.

### 1-1. 저자가 직접 제시한 계산

원문 결론은 펫 방어구의 방어력 절댓값을 2로 나누고 소수점 이하를 버려 랜덤 감소의 상한을 얻는다는 것이다.

```text
armor_reduction_max = floor(abs(pet_armor_AC_bonus) / 2)
random_reduction   = random integer in [0, armor_reduction_max]
damage             = attack_damage - random_reduction
```

- 방어구 -4 → 상한 2.
- 방어구 -7 → 상한 3.
- 방어구 -13 → 상한 6.
- 원문에서 **균등한 난수의 개별 확률을 엄밀하게 검증한 것은 아니다**. 원문의 표현은 '랜덤 감소'다.

이 실험에서는 기본 AC가 +10인 펫에게 방어구만 입혔으므로 아래와 같이 **대수적으로 같은 형태**로 적을 수 있다.

```text
Rmax = max(0, floor((10 - final_AC) / 2))
```

이 식은 **해당 펫의 기본 AC +10에 기초한 재표현**이다. **모든 레벨·종족·몬스터에서 AC +10을 출발점으로 사용한다고 증명된 적은 없다.** 특히 몬스터 AC -100에 이 식을 대입해 55라고 계산하는 것은 검증된 몬스터 값이 아니라 확장 가설이다.

### 1-2. 몬스터로의 일반화는 원저자의 추측

공격한 주체가 몬스터였던 것과 달리, 실제로 피해를 감소시킨 **피격 대상은 펫**이다. 저자는 '펫과 몬스터의 피해 감소가 같다고 생각한다'고 주장했으나, 일반 몬스터를 피격 대상으로 삼아 AC를 바꿔 검증한 자료는 이 글에 없다. **몬스터 자체의 DR을 9,045회 측정한 연구가 아니다.**

## 2. 일본 2015년 '지저호 거북이 DR-15/BIG'의 근거 수준

2015-09-17 일본 Starsleaf: [리니지 관련 회고·보스 DR·무기 DPS](https://blog.livedoor.jp/starsleaf/archives/1986487.html).

글에 **地底湖の亀（DR-15/BIG）**라는 표기가 있다. 그러나 거북이를 공격한 원시 피해, 표본 수, AC, 회복량, DR 15 도출 과정이 제시되지 않는다. 일본 저자도 전체 계산이 본인 경험에 기반하고 다를 수 있다고 명시한다.

독립적인 대만 LoA 3.63 서버 데이터베이스의 [地底巨王龜 / 지저 대왕 거북 / NPC 45422](https://loalineage.com/mob/45422/%E5%9C%B0%E5%BA%95%E5%B7%A8%E7%8E%8B%E9%BE%9C?locale=zh-TW)는 **AC -20, 별도 피해 감소 0, HP 2400, 5초당 HP 회복 73**을 표시한다.

여기에 대만 **펫 실험의 확장 가설**을 대입하면:

```text
(10 - (-20)) / 2 = 15
```

숫자 **15는 일치**한다. 하지만 이것만으로 **일본의 地底湖の亀와 LoA의 地底巨王龜가 동일 NPC/시기/설정이라는 증거가 되지 않는다**. LoA는 NC 원본 DB가 아니며 해당 기록의 '별도 DR 0'은 일본의 DR 15와 개념상 충돌할 수도 있다.

가설 A: 일본의 DR 15는 'AC 기반 랜덤 감소 상한 15'를 의미했다.
가설 B: 일본의 DR 15는 'NPC별 고정 차감값 15'를 의미했다.
가설 C: 서로 다른 버전/몬스터를 연결해 우연히 15가 일치했다.
**어느 모델도 현재 확정할 수 없다.**

## 3. RKern에서 구별해야 할 피해 모델

| 후보 | 몬스터가 받는 물리 피해(개념식) | 근거 |
|---|---|---|
| A — 몬스터 AC 랜덤 | `max(0, D - U[0, floor((10-AC)/2)])` | 펫 실험을 몬스터로 확장한 **미검증 가설** |
| B — 몬스터 고정 DR | `max(0, D - R_fixed)` | 공개 L1J의 몬스터별 설정값 처리 방식 |
| C — 둘 다 | `max(0, D - U[0,Rmax] - R_fixed)` | 가능성만 있음. **중복 감산 위험** |
| D — HP 단계별 DR | `max(0, D - R(HP%))` | 일본 보스 관찰에서 제기된 가설. 숫자 미확인 |

AC가 **명중 회피**와 **피격 시 피해 감소**에 동시에 쓰이는지는 반드시 별개로 실험해야 한다.

### 3-1. 단순 예시 (본서버 실측이 아님)

몬스터 AC -20에 확장 가설 A 적용: `Rmax = 15` → 가상 원피해 50일 때 실제 피해 35~50, 균등 정수 감소라면 평균 42.5. 반면 **고정 DR 15**라면 매번 35.

AC -100에 동일하게 외삽하면 `Rmax=55`, 평균 감소 27.5라는 *가설적 계산*이 나온다. **이 값으로 NPC를 곧바로 수정하면 안 된다.**

## 4. 원본에 가깝게 검증하는 실험 설계

1. 몬스터 **같은 NPC ID/동일한 스폰 버전**의 AC, HP, HPR, 별도 DR 필드를 고정해 채집한다. 대만 LoA의 NPC 45422를 일본 거북이와 동일 NPC라고 전제하지 않는다.
2. 공격자의 피해 난수폭을 최대한 줄이고, 별도 마법 발동·무기 특수효과·추가타·속성 효과·치명타·반사·흡혈을 분리한다.
3. 명중 판정 결과와 실제 피해를 분리 기록한다. **피해 0을 명중 실패로 자동 분류하면 안 된다**.
4. HPR이 발생하기 전 짧은 구간의 HP 변화와 처치 타수를 수집한다. 자연 회복 틱이 겹친 표본은 따로 표기한다.
5. 동일 몬스터의 고정 공격력 D를 여러 단계(예: 30·40·50·60)로 교차하고, 가능하면 NPC AC만 변경한 통제 실험을 사용한다.
6. 동일한 공격력에서 피해가 D-R 하나의 값에 모이는지(고정 DR), `D, D-1, …, D-Rmax`에 분포하는지(랜덤)를 비교한다.
7. 실제 몬스터별 실험이라면 표본을 1,000회 이상 확보하고 히스토그램·평균·분산·최소/최대 및 신뢰구간을 기록한다.
8. C 모델은 B 모델보다 실제 분포 적합도가 유의하게 좋아지는지 확인해 **이중 차감 도입을 억제**한다.
9. 보스 단계별 DR은 HP·시간별 HPR·스턴 중 실제 공격 횟수·피격 무적 등의 교란 요인을 제외한 후에만 판단한다.

## 5. 현재 판정과 코드 적용 원칙

- **확인:** 대만 PC판 펫 대상 9,045회 AC·랜덤 감소 실험; 일본 DR-15 표기; 대만 서드파티 몬스터 AC -20 및 별도 DR 0.
- **미확인:** NC 본서버 몬스터별 AC→DR 공통 공식; 지저호 거북이 DR 15의 산출 원시자료; 일본 거북이와 LoA 거북이의 정확한 매칭; 확률분포가 균등한지; 고정 DR과 랜덤 DR의 병용.
- **RKern 작업:** 현재 몬스터 피격 경로에서 이미 AC 기반 감소 또는 NPC 고정 DR이 처리되는지 먼저 감사. **코드를 수정하거나 임의로 DR 15/55를 입력하지 말 것.** 별도 데이터 검증 후 최소 변경.
- 이 문서는 **연구/감사 메모**다. Java 소스 수정과 인게임 검증은 하지 않았다.
