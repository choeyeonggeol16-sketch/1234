PSS V9 — HP·MP바 하단 고정 배치

V8에서 실제 HP·MP 값이 변하는 것을 사용자가 확인했습니다.
이번 변경은 배치만입니다. 기존 HP·MP 읽기, 그림, PSS 동작과 서버 통신은 V8 그대로입니다.

V7/V8이 동작하던 2019 게임 폴더에서 게임을 완전히 종료하고 DLL을 백업한 뒤
Pss2019.dll만 교체하세요. 기존 INI는 유지합니다. 서버 src·DB 수정과 Apply 재실행은 필요 없습니다.

기본 위치는 게임 창의 하단에서 128픽셀 위에 바의 아래쪽을 맞춘 가로 중앙입니다.
창이 이동하거나 높이가 달라지면 같은 하단 간격을 유지합니다. 드래그 이동 기능은 없습니다.
이는 시험용 바의 하단 배치이며, 원본 클래식 용머리 리소스를 가져온 것이 아닙니다.
기존 UI·원래 피바는 아직 숨기지 않았습니다. 기존 바 완전 교체와 용머리 버튼은 이번 범위가 아닙니다.

V8용 INI에 Top=44가 있어도 기본 Anchor=bottom에서는 사용하지 않습니다.
설정은 선택 사항이며 기존 파일의 같은 섹션 값을 수정합니다.
[VitalsHud]
Enabled=1
Anchor=bottom
Bottom=128
OffsetX=0

Bottom 값을 줄이면 바가 더 아래로 내려갑니다. 늘리면 위로 올라갑니다.
OffsetX는 가로 이동입니다. 게임을 다시 실행하면 적용됩니다.
기존 상단 시험 배치가 필요할 때만 Anchor=top, Top=44를 사용합니다.
Enabled=0은 추가 바만 끄며 기존 게임 UI나 PSS를 끄지 않습니다.

시작 로그: PSS V9 bottom-docked HP/MP HUD trial loaded
위치 로그: HUD HP/MP anchor=bottom offset=128
게임 창 안에 바 전체가 들어가지 않는 설정이면 표시하지 않습니다.

전체 DLL은 PE32 MinGW -Wall -Wextra -Werror로 빌드했고 최종 DLL 로드 검사를 통과했습니다.
위치 변경은 실제 Windows 게임에서 아직 확인하지 않았습니다. 하단 위치가 채팅창 또는
기존 UI와 겹치는지, 원래 HP·MP와 계속 일치하는지 확인해야 합니다.
V8에서 통과한 수치 읽기·PSS·그림·좌표 검사 자료는 이전 버전의 검증 기록입니다.
서버 src는 V8과 바이트 단위로 동일합니다.
