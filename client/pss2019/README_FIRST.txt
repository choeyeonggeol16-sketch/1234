PSS V11 - 클래식풍 HP/MP HUD (사용자 제공 영상 참조 재현)

실행에는 아래 두 파일이 필요합니다.
  Pss2019.dll
  Pss2019ClassicHud.dat
두 파일 모두 기존 Pss2019.dll이 있는 게임 폴더에 나란히 복사하세요.
기존 Pss2019.ini는 변경하지 마세요.

설치
1. 게임을 완전히 종료합니다.
2. 기존 Pss2019.dll을 별도 폴더에 백업합니다.
3. ZIP 안의 Pss2019.dll 및 Pss2019ClassicHud.dat를 함께 복사합니다.
4. 게임을 실행하고 피격/물약/MP 사용 시 상태 변화를 확인합니다.

수정 내용
- HP는 중앙을 기준으로 채워져서, 피가 빠지면 왼쪽부터 비워집니다.
- MP는 왼쪽에서 오른쪽으로 차는 기존 동작을 유지합니다.
- HUD를 784x80으로 넓혀 본서버 영상에 가까운 비율로 배치했습니다.
- 이전 마름모/삼각형으로 만든 임시 장식은 제거했습니다.
- 사용자 제공 영상에서 장식을 분리해 재구성한 별도 그림 데이터 파일을 로드합니다.
- 그래픽 데이터는 최초 한 번 읽고 캐시합니다. 매 프레임 파일 접근 없음.
- 원래 HP/MP 읽기, PSS, 서버/DB/통신 규약은 변경하지 않았습니다.

미완료
- NC 원본 UI 파일이 아니라 사용자 제공 영상 기준의 재현 이미지입니다.
- Pss2019ClassicHud.dat가 없으면 용머리와 장식이 표시되지 않습니다.
- 기존 HP/MP바 숨김, 미니맵 이동/숨김, 창 포커스 해제 문제는 수정하지 않았습니다.
- Windows 32비트 DLL 빌드 및 바이너리 검증은 통과했지만 실게임 확인은 별도입니다.
- 2019-02-15 클라이언트(19.02.15.1002) 전용입니다.

기존 Pss2019.ini [VitalsHud] 설정은 그대로 유지합니다.
Enabled=1
Anchor=bottom
Bottom=128
OffsetX=0
