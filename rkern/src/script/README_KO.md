# 아이템 옵션 편집

서버 실행 폴더의 `script` 폴더에 수정할 정의 파일을 넣습니다. 기본 파일은 소스의 `rkern/src/script`에 있습니다. 각 파일은 UTF-8로 저장합니다. 탭으로 구분된 파일에서는 기존 행의 탭을 유지합니다.

| 파일 | 수정할 값 |
| --- | --- |
| `equipment-base.txt` | 무기·방어구 기본 능력치, 타격치, 무게 감소, 마법명 |
| `equipment-options.txt` | 아이템 ID별 추가 능력치, 강화 구간, 장신구 보너스, 특수 속성 |
| `equipment-registered.txt` | 귀걸이·견갑·문장·티셔츠 등의 직업·강화별 등록 효과 |
| `equipment-blessing.txt` | 방어구 축복 단계별 효과 |
| `doll-options.txt` | 인형 기본 효과, 자동 회복량, 명중 시 발동 종류 |
| `doll-potential.txt` | 인형 잠재력 효과와 툴팁 |
| `cooking-options.txt` | 요리 효과, 지속 시간(초), 아이콘, 중복 적용 그룹 |
| `etc-item-tooltips.txt` | 일반 아이템 설명, 스킬북 분류, 카드 요약 툴팁 |

무기·방어구 기본 옵션은 `equipment-base.txt`에서 읽습니다. DB에 있는 모든 무기·방어구 ID마다 행이 필요하며, 행에서 생략한 숫자 필드는 0입니다. 이름, 외형, 직업 제한, 분류, 거래 조건 같은 메타데이터는 DB에서 읽습니다.

기본 옵션 파일을 저장한 뒤 GM 명령 `.리로드 아이템`을 실행하면, 새로 생성하거나 캐릭터 재접속 시 불러오는 아이템에 새 수치가 적용됩니다. 리로드 전에 만들어진 아이템은 이전 템플릿으로 장착·해제를 처리합니다. 정의에 빠진 ID나 잘못된 값이 있으면 서버 시작 또는 리로드가 실패하며, 리로드 실패 시에는 이전 템플릿을 계속 사용합니다. 그 밖의 정의 파일은 서버를 재시작할 때 읽습니다.

`equipment-options.txt`에서 `MR:4:2`는 마법 방어력 4에 인챈트 수치당 2를 더한다는 뜻입니다. 인형과 요리의 수치는 각 파일의 해당 아이템 또는 프로필 아래에서 바꿀 수 있습니다. `doll-potential.txt`의 `{VALUE}`는 실제 적용되는 효과값으로 표시됩니다. 인형의 명중 시 발동 확률과 피해 범위는 기존 `config/MagicDollProc.properties`를 사용합니다.

일반 아이템 툴팁은 아이템 ID와 옵션 이름으로 찾습니다. 한 줄에 ID를 쉼표로 연결하거나 `45001..45007`처럼 범위를 쓸 수 있습니다. `TEXT@0`~`TEXT@7`은 직업별 문구이며, `${KEY}`는 서버 설정에서 값을 읽습니다. 요리와 인형, 버프 주문서의 효과는 실제 효과 정의에서 가져옵니다.
