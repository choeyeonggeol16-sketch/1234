# RKern 아이템 도메인 리팩토링 15차 — 검사 보고서

## 범위
14차 전체 SRC에서 아이템 기능별 분리만 수행. 효과 본문, 아이템 ID/메시지, RNG 호출·강화 확률, COMMIT 이전/이후 순서 유지. 네트워크·브로드캐스트·NPC·DB 공통 코드 및 CIO 공통 실행 구조는 변경하지 않았음.

### 분리 결과
- 퀘스트 수리/조합/보상 7개 메서드→7개 전용 클래스. `ItemActionDispatcher` 호출 갱신.
- 직업별 마법서 8개 메서드→8개 전용 클래스. `UnlistedItemRouter` 호출 갱신.
- 스타터 장비 지급함/순백의 티 교환 2개 메서드→2개 전용 클래스.
- 레벨 82·84·86·88·89·90 지급 코드→6개 전용 클래스. `LevelMilestonePackages`는 단순 ID 라우터로 보존.
- 잊섬/해적섬 귀환, 상점 부적, 혈맹/여관 귀환→3개 전용 클래스. `ReturnAndTeleportItems`는 단순 ID 라우터로 보존.
- 초록 물약/용기 물약/열매 물약의 총 35개 ID→3개 전용 소비 클래스. `MovementPotionConsumables`는 분기 라우터로 보존.
- 룬 마력 제거, 목표 정화, 무기 변환, 생명의 눈 제작→4개 영속 거래 클래스.
- 직업 패키지/봉인 장비 교환/아데나 수표 교환→3개 영속 거래 클래스.
- 직업 선물상자, 관리 선물상자, 레거시 선물상자 2종→4개 클래스.
- 확성기/약혼반지/캐릭터 이름 변경/보호 혈맹 가입→4개 클래스.

7개 혼합 클래스를 제거. 신규 전용 클래스 44개.

## 검증
- Java 21 JDK 컴파일러 AST 파서: 전체 src 1,943개, 구문 오류 0.
- 원본 몸체/케이스: 62개 영역 동등성 및 참조 누락 검사 통과.
- 원본 대비 typed Java 21 실행: 레벨 4,096 / 마법서 59,520 / 물약 21,312 / 영속 재화 거래 29,376 = 114,304건, 효과/반환·메시지·입출금 호출 로그 일치.
- 10·12·13·14차 테스트와 11차 무기 강화 별도 typed 컴파일, 방송 114차 오류 주입/송신 회귀 테스트 통과.
- 11차의 기존 원문 분기 소스 위치에 종속된 `test_phase11.py`는 분리 후 소스 위치가 바뀌므로 기존 방식으로 실행하지 않음. 이 영역은 새 15차 바디 동일성/Java21 typed 테스트가 검증함.

## 남은 검증
- 전체 게임 외부 의존성 타입 컴파일, 실제 MySQL/CacheD 승인 실패 및 ACK 소실 실험, 강화·마법서·텔레포트·레이드 실서버 사용 검증, 5,000명 부하 검증은 완료하지 못했음.
- 아이템 함수 폴더의 특수 단일 기능 처리(`ArmorEnchantTargetRules`, `RecruitStarterKit`, `PassiveSkillBooks` 등)는 별도 기능별 파일로 이미 분리되어 있지만 규모가 크므로 향후 내부 책임 분할 또는 동작 검증 가능.
