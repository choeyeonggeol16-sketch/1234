기준: `RKern_ItemOnly_SummonWand_PetConsume_MultiPhase143_144_FULL_SRC_20261118.zip` (144차).

## 수정

- 펫 목걸이 40314/40316을 사용할 때 기존에는 `withdrawPet`으로 먼저 월드 펫을 생성하고 `consumeItem(41160, 1)`을 나중에 호출했음.
- 피리(41160) 인스턴스가 실제 인벤토리에 존재하는지 확인하고 `UseDurableConsume`으로 CacheD 영속 차감 완료 후에만 기존 `withdrawPet`을 호출하도록 변경.
- `canWithdrawPet` 사전 검사를 분리하여 맵 제한, 전쟁 지역, 펫 중복, CHARISMA 한도, 펫 목걸이 소유, 펫 테이블/NPC 템플릿 유효성을 **차감 전에** 확인. 커밋 이후에도 동일 검사를 재실행.
- 사용 요청의 원본 목걸이 객체 ID와 실제 소유한 목걸이 객체가 정확히 동일해야 실행. 커밋 이후에도 같은 객체인지 재확인하여 목걸이 교체/회수 중 낡은 참조로 소환하지 않음.
- `ItemActionResult.STOP`으로 비동기 거래 제출 직후 일반 완료 처리를 차단. 기존 사용 완료 시각/재사용 제한은 커밋 콜백에서만 반영.
- NPC, 네트워크, 방송, DB/CacheD 공통 코드는 변경하지 않음.
