# 스킬 효과 실행과 적용값 분리

기준은 통합 브랜치 `7d1d97c`다. [요구사항](../../../reports/NC_L2Server_SkillEffect_Remaining_Engine_Implementation_20261120.md)

- `CSkillInfo`가 부팅 시 동결되는 ID 정의를 보유한다. `CSkillEffect`의 즉시 실행, 조건 검사, 순수 스탯 보정, 시작, 종료 경로를 연결했다. 어드밴스는 HP와 MP, 어스 드래곤은 AC와 MR을 각각 독립 효과로 순회한다.
- 프라이드, 기간틱, 어드밴스, 실드, 샤이닝 아우라, 일루션 다이아몬드 골렘, 섀도 아머, 어스 드래곤의 능력치를 독립 보정 영역으로 옮겼다. 부여 당시 적용량은 기존 타이머 컨테이너의 작은 primitive 배열에 기록하며, 재계산은 현재 적용된 소스의 합계를 반영한다. 재계산이 적용·종료 패킷이나 타이머를 재실행하지 않는다.
- 현대 스킬의 HP는 한글 이름의 레거시 버프와 포텐셜이 쓰는 공유 HP 저장값에서 분리했다. 프라이드 해제 후 기간틱과 기존 HP 보정이 남으며, MR 상한에서 어스 드래곤을 해제해도 다른 보정값을 잃지 않는다. 기존 공개 스탯 API에서 합산값을 읽는다.
- 캐스트는 기존 PC 컨트롤러에서 시작·보정·타이머를 처리한다. 각 핸들러의 시작·종료 알림 순서를 보존했고, 지원 NPC 어드밴스도 동일한 보정에 연결했다. 갱신은 기존 타이머 슬롯에서 처리한다. 타이머만 제거하거나 전체 초기화할 때 분리된 보정값도 정리한다.
- 포그 오브 슬리핑, 판타즘, 다크 블라인드가 겹치면 마지막 수면 효과가 끝날 때 해제한다. 만료용 배열은 처음 만료할 때만 만들고, 적용값 배열은 이관된 효과를 사용한 캐릭터만 만든다.

Java 21 전체 소스 컴파일과 헤드리스 회귀를 통과했다. 기존 버프 6종의 적용·재시전·종료에서 HP·MP·AC·MR과 타이머 18개 스냅샷이 기준과 일치했다. 실제 PC 컨트롤러의 적용·제거, 타이머 갱신, 만료, 이전 heartbeat generation 무효화, 수면 중첩을 추가 검증했다. 시전 ID 310개, 종료 ID 297개와 교집합 196개가 기준과 일치한다. [숫자 ID 목록](NUMERIC_SKILL_INVENTORY.csv)

추가로 N샵 능력치 4종, 속성 저항 5종, 드레스 계열 2종을 이관해 독립 적용값을 쓰는 버프가 19종이 됐다. 중첩된 저항과 기존 장비 보정은 한 버프를 지워도 보존된다. 상한을 넘는 저항을 해제해도 원래 수치로 돌아온다. N샵 사용과 로그인 복원은 모두 기존 시전 경로를 거친다. 복원 시 DB에서 읽은 남은 시간을 넘기는 호출을 확인했으며, 실 DB로 재접속하는 검증은 남아 있다.

드레스 이베이젼, 아쿠아 프로텍터, 솔리드 캐리지, 워터 드래곤 비늘, 린드비오르 비늘의 ER/DG까지 이관했다. 현재 독립 적용값을 쓰는 버프는 총 24종이다. 5종의 재시전·단독 해제·장비 보정 보존과 실제 PC 컨트롤러의 워터 드래곤 비늘 갱신·전체 클리어를 검증했다. 종료 메시지 조회와 클라이언트 패킷 비교에는 테스트 서버 DB가 필요하다.

프리징 아머, 샤이닝 아머, 레지스트 매직은 시전과 로그인 복원이 같은 적용량을 쓰도록 연결했다. 복원 핸들러를 호출한 뒤 재시전과 개별 해제를 검증했다. 독립 적용값을 쓰는 버프는 27종이며, 실제 접속과 저장 DB를 포함한 검증은 남아 있다.

글로잉 아우라, 일루션 오거, 인챈트 어큐러시의 근거리 명중과 대미지를 이관했다. 인챈트 어큐러시의 로그인 복원도 동일한 보정을 사용한다. 명중·대미지 상한, 중첩, 능력치 변경, 개별 해제 후 기존 수치 보존을 검증했다. 독립 적용값을 쓰는 버프는 총 30종이다.

N샵 대미지 버프의 근·원거리 대미지와 N샵 주문력·일루션 리치의 주문력을 이관했다. 두 주문력 버프의 중첩, 제거 후 잔여 보정, 근·원거리 대미지의 재시전과 원복을 검증했다. 독립 적용값을 쓰는 버프는 총 33종이다.

N샵 HP/MP 버프의 소지 무게 보정과 N샵 대미지 감소도 수명에 연결했다. HP/MP 버프 종료 때 현재 HP/MP가 새 상한에 맞춰지고 장비의 무게·감소 보정 및 다른 버프가 유지되는지 검증했다. 독립 적용값을 쓰는 버프는 총 35종이다.

N샵 PvP 대미지·감소와 기술·정령 내성을 추가해 독립 적용값을 쓰는 버프가 38종이 됐다. 기술과 정령 내성의 독립 해제, 수치 상한 뒤 장비 보정 보존, 재시전을 검증했다.

## 남은 검증과 이관

기존 복합 콜백을 사용하는 나머지 스킬, 한글 이름 레거시·포텐셜 간 HP 소유권, 이동·행동 제한의 다른 원인, 명시적 로그인 복원 핸들러는 추가 이관 대상이다. 여기서 검증한 수명과 수치는 헤드리스 환경 기준이다. DB의 종료 메시지와 실서버 패킷 바이트, 전 스킬의 분기별 동등성, JFR 및 고부하는 미검증이다.

## 2026-11-21 후속 이관

클리어 마인드, 피지컬 인챈트 STR/DEX, 레지스트 엘리멘탈, 엘리멘탈 프로텍션, 인사이트, 미러 이미지, 언캐니 닷지 8종을 추가했다. 독립 효과 정의 46종, 기존 시전 콜백 249종이다. 피지컬 인챈트의 지원 NPC 부여도 기존 CIO owner pump 시작을 공유한다. 엘리멘탈 프로텍션은 적용 시점의 속성과 정령 관통을 같은 captured 값에 기록하므로 속성이 변경된 뒤에도 처음 적용한 값만 제거한다. CON은 기존 STR/DEX/INT/WIS packed word를 long으로 확장하고, 정령 관통은 기존 특수 저항 word의 미사용 6번째 byte를 이용한다. DG 시전·종료 시 기존 속성 방어 갱신 패킷을 유지한다.

실제 Java 컨트롤러 및 복원·중첩·해제 회귀를 확장하고 스킬 전용 Java 21 CI를 추가했다. 통합 브랜치 `32d0a0b`로 전체 컴파일과 로컬 헤드리스 회귀를 통과했다. 실 DB 재접속·패킷 바이트 비교·JFR 및 5,000명 부하 검증은 남아 있다.

### 헤이스트·슬로우와 NPC 발묶임

- 헤이스트 계열은 스킬, 물약, 장비 보정이 남아 있으면 첫 종료에서 속도를 유지한다. 일반 슬로우와 몬스터 슬로우가 겹칠 때도 마지막 타이머가 끝나야 풀린다. 몬스터 슬로우 2종의 종료 핸들러를 추가했다. 시전 ID 310개, 종료 ID 299개, 교집합 198개, 합집합 411개다.
- 가속 시전이 슬로우를 상쇄했거나 장비 가속 때문에 효과가 적용되지 않았으면 가속 타이머를 만들지 않는다. 초록 물약 계열의 슬로우 해제는 몬스터 슬로우도 처리한다.
- NPC 발묶임은 파워 립·데스페라도·바인드 상태의 기존 타이머에서 읽는다. 한 타이머가 끝나도 다른 발묶임과 별도 마비 상태가 남는다. 발묶임 플래그를 제거했고, 이동 판정은 타이머를 한 번 순회한다.
- Java 21 전체 소스 1,934개 컴파일과 헤드리스 회귀를 통과했다. 실제 클라이언트의 속도·마비 패킷, 여러 원천이 겹친 브레이브 계열, 스턴·시전 제한은 추가 검증 및 이관 대상이다.

### 브레이브·스턴과 복합 능력치

- 브레이브 종료 및 물약·장비 전환은 남은 가속을 다시 선택한다. 일반 속도와 허리케인·포커스 웨이브의 클라이언트 모드를 구분했다. 스턴은 NPC 파라미터와 분리해 자체 타이머로 유지하고, PC 이동·행동·시전 및 주문서에서 같은 스턴 그룹을 확인한다. 중첩 스턴이 남아 있으면 해제 패킷을 보내지 않는다.
- 프라이드·기간틱·포텐셜은 각각의 보정만 제거한다. 포텐셜은 시전 당시 HP, MP, MR, SP, ER, DG를 기록한다. 레거시 버프의 레벨 갱신에서 최대 HP를 중간에 내리는 동작을 제거했다.
- 갓 버프, 파이어 드래곤 비늘, 방어·공격 버프, 공포·패닉·디지즈·위크니스 계열을 추가했다. 로그인 갓 버프는 명중을 부여하지 않는 기존 규칙을 유지하며 종료에도 명중을 건드리지 않는다. 지원 NPC 버서커스와 사막 디지즈는 일반 시전과 다른 적용값을 기록한다. 파이어 드래곤 비늘 내성 패킷은 합산값을 한 번 전송하도록 바꿨다. 브레이브 아우라는 시각 효과 타이머, 마나 회복·흡수·해제 등 5개 시전은 즉시 실행으로 정리했다.
- 현재 독립 스탯 보정은 66종이다. 시전 310개는 독립 63개, 즉시 실행 20개, 시각 타이머 1개, 기존 콜백 226개다. 직접 부여 전용 보정 3개는 시전 수에 별도로 포함된다. 종료 ID는 299개다. [숫자 ID 목록](NUMERIC_SKILL_INVENTORY.csv)

### 5,000개 캐릭터 로컬 비교

기준은 `5e711ac`다. Java 21, G1, 활성 CPU 수 2, 256 MiB 초기 힙과 1 GiB 최대 힙에서 양쪽에 JFR `profile`을 켰다. 캐릭터 5,000개에 갓 버프와 파이어 드래곤 비늘을 겹쳤고, 해제 후 재부여 500,000회씩 측정했다. 해제 후 능력치 원복을 캐릭터 전원에서 확인했다. 테스트는 서버 모델과 스킬 경로를 호출하고, DB·클라이언트 연결과 실제 타이머 스케줄러는 모의 경로를 사용한다. [벤치마크 코드](BenchmarkSkillEffectLifecycle.java)

| 지표 | 기준 | 변경 |
| --- | ---: | ---: |
| 해제·재부여 묶음 p99 | 315 ns | 561 ns |
| CPU 시간 | 185.3 ns/묶음 | 393.9 ns/묶음 |
| 측정 스레드 할당 | 0.1 B/묶음 | 0.1 B/묶음 |
| 측정 구간 GC | 0 | 0 |
| 활성 상태 프로세스 힙, GC 직후 | 55,401,928 B | 57,403,352 B |
| 일괄 종료 후 프로세스 힙, GC 직후 | 55,369,144 B | 56,564,416 B |

JFR 전체 녹화의 GC는 양쪽 6회였고, 할당 샘플은 기준 139개와 변경 146개였다. 변경판에서 적용값을 재계산하는 CPU 비용과 활성·종료 후 힙 사용량이 늘었다. 장시간 실서버 재접속, 네트워크 p99, 잔존 객체의 소유권 분석, 클라이언트 패킷 비교는 추가 검증 대상이다.
