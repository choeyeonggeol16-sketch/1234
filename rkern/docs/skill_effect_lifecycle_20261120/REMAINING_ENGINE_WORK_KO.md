## 다음 수정 순서

1. **능력치와 내성의 남은 시전·복원 경로.** 클리어 마인드는 STR·DEX·INT 변경 알림과 로그인 전용 아이콘을 보존한다. 피지컬 인챈트 STR/DEX는 일반 시전과 지원 NPC 직접 부여를 함께 바꾸고, 스킬 슬롯 교체와 재시전 때의 타이머 정책을 맞춘다. 레지스트 엘리멘탈, 엘리멘탈 프로텍션, 인사이트, 미러 이미지, 언캐니 닷지는 공용 타이머 경로를 유지한다. 엘리멘탈 프로텍션은 종료할 때 시전 시 적용된 속성과 정령 관통만 지운다. 각 그룹에서 취소·만료·로그인 복원과 장비 보정 보존을 확인한다.
2. **이동 속도와 행동 제한.** 헤이스트·슬로우 및 브레이브 계열의 스킬, 물약, 장비, 지원 NPC, 패시브, 로그인 복원 경로를 먼저 목록화한다. 가장 먼저 끝난 효과가 남아 있는 속도나 제한을 풀지 않게 처리하고, 기존 속도 상쇄·우선순위와 패킷을 비교한다. 수면 중첩은 적용됐다. 스턴·이동·행동·시전 제한은 사망과 강제 해제까지 확인한다.
3. **복합 효과와 레거시 원복.** 한글 이름 기간틱·프라이드·포텐셜 사이 공유 HP, 갓 버프·드래곤 비늘·오라 계열의 복합 보정, 공격·회복·해제 혼합 효과를 입력 경로별로 조사한다. 타이머만 있는 효과와 스탯을 직접 적용하는 효과를 ID별로 기록하고, 이관한 경로의 중복 적용과 종료 원복을 제거한다.
4. **통합 회귀와 메모리·부하 검증.** 실제 DB로 로그인·재접속·사망·취소·만료를 재현하고 PC/NPC/동료의 능력치와 클라이언트 패킷 바이트·순서를 비교한다. 동일 시전/만료 부하에서 JFR 할당량, 잔존 힙, GC, CPU, p99를 측정한다. 5,000개 활성 캐릭터 시나리오에서 반복 만료·재시전·접속 종료 후 보정과 참조가 정리되는지 확인한다.
