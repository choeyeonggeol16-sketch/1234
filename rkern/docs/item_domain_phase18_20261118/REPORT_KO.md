# RKern 아이템 리팩토링 18차 — 과분리 통합·사용 시 할당 감소

기준: 17차 전체 SRC. 네트워크/방송/NPC/DB 공통 코드는 수정하지 않았습니다.

## 변경점
- 레벨 변신 분기 9개 소형 클래스 제거 → `LevelPolymorphScrollEffects` 안에 전부 원래 본문 그대로 통합. 변신 번호·검사 순서·지속시간 동일.
- 레벨 보상 6개 소형 클래스 제거 → `LevelMilestonePackages` 안에 전부 원래 본문 그대로 통합. 아이템 검사·직업별 보상·지급 호출 순서·영속 receipt 유지.
- `Telbookitem`: 오만/지배의 탑 10칸 ID 배열을 사용 시마다 생성하던 2개 분기의 `int[]` 제거하고 연속 아이템 ID 계산으로 교체. 매스 텔레포트의 사용 시 `new Random()`은 `ThreadLocalRandom.current()`로 교체. `nextInt(3)+1` 호출 횟수·범위는 유지하나 난수 생성기와 실제 연속 난수값은 달라질 수 있음.
- `IdentificationAndScrollItems`: 식별 메시지용 `StringBuffer` 및 중간 문자열 연결을 하나의 문자열 연결로 교체. 장비가 아닌 아이템도 기존처럼 빈 메시지를 전송함.

**실행 경계 유지**: 입력 아이템 차감/지급, 강화 확률, 스킬 효과, CDB/CacheD 트랜잭션, 타 스레드 실행 구조에는 변경이 없습니다. 이번 최적화는 메모리 할당 두 지점에 초점을 둔 국소 변경이며, TPS/GC 개선 폭을 계측하지 않았습니다.

## 검증
- 생산 Java 1,954개 Java 21 전 파일 구문 검사: 오류 0.
- 원본↔수정 Java 21 타입 컴파일 후 변신·보상 8,704 시나리오 동작 비교 일치.
- 텔레포트 Java 21 타입 컴파일 후 76개 결정적 경로 동작 비교 일치 + 매스 텔레포트 난수 9,000회 좌표 범위 테스트 통과.
- 식별 주문서 Java 21 타입 컴파일 후 288개 입력에서 원본과 메시지/변경 순서 일치.
- 변경되지 않은 11~17차 관련 아이템 회귀검사 및 방송114차 실패주입/5,000수신자 스트레스 테스트 통과.
- 10차 및 15차 레거시 소스 위치 검사는 삭제한 개별 파일명에 묶여 있어 이제 적용 불가; 새로운 통합 클래스 동작 비교와 구조 검사로 해당 부분을 대체함.
- 전체 게임 의존성 통합 컴파일, 실제 MySQL/CacheD 장애, 인게임 테스트 및 실측 할당률은 **미검증**.
