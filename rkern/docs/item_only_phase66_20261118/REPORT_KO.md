# RKern 아이템 전용 리팩토링 66차 (2026-11-18)

## 작업 범위

65차 전체 SRC를 누적 기준으로 유지했다. **NPC, `CS_NpcAction.java`, NPC 퀘스트, 네트워크·방송, CacheD 공통 코드에는 변경이 없다.** 변경된 생산 파일은 전부 `src/l1j/server/server/model/item/function/` 하위다.

## 코드 변경

- `MovementPotionConsumables`: 과도하게 분리된 초록·용기·열매 물약 사용기 3개를 기존 진입 클래스의 private 정적 메서드로 통합. 원본 메서드 몸체(조건·실행·소모·메시지)를 변경하지 않고 호출부 연결만 교체했다. 메서드 이름이 가져온 `PotionEffects.useFruit`를 가리지 않도록 `useFruitPotion`으로 정했다. 기존 분리 클래스 3개 삭제.
- `BravePotion`: 충돌 효과 체크 `int[9]`을 사용마다 생성하지 않고 클래스당 1회 생성.
- `TargetPolymorphEffects`: 단풍막대용 변신 ID 표를 사용당 생성하지 않고 재사용. 난수 생성기, `nextInt` 위치·범위 유지.
- `PetAndSummonItems`: 소환 NPC ID 표를 클래스 공통 상수로 유지. `CommonUtil.random(3)` 호출 유지.
- `ProtectedClanJoinItemUse`: 1개 혈맹명 배열의 호출당 생성을 제거. `CommonUtil.random(1)` 호출 유지.
- `EquipmentExperienceBonuses`: 특정 장비(900116) 강화별 경험치 배율표의 호출당 생성을 제거. 기존 double 리터럴 및 범위 검증 유지.

## 검증

- Java 21 전체 생산 소스 1,922개 **구문 파싱 오류 0건**.
- 원본 메서드 추출·Java 21 타입 컴파일 및 실행 비교: 용기 물약의 효과 제거 5,120건, 장비 경험치 배율 1,212건, 선택 테이블의 동일 시드 난수 비교 300,000건 일치.
- 이동·용기·열매 물약: 생산 메서드 본문 동일성 및 Java 21 타입 실행 비교 **3,648건**. 모든 아이템 ID·직업 플래그 32조합·효과 실패/인벤토리 차감 실패를 비교.
- 기존 이동·용기 물약 회귀검사(실제 `MovementPotionEffects` vs 이전 버전): **17,280건** 통과.
- 기존 스타터 패키지 521건, 구형 선물상자 1,381건 거래·롤백 시험 통과.
- 변경 생산 파일 6개, 삭제 3개, 신규 생산 클래스 0개.
- 모든 다른 생산 파일과 `CS_NpcAction.java`는 65차에서 byte-identical.

## 성능 및 검증 한계

**가변 데이터가 아닌 고정 표의 매 호출 할당 후보 5개를 제거**했다. 정적 표로 이동한 것이 힙 전체 할당률을 얼마 줄였는지는 측정하지 않았다. JIT 탈출 분석에 따라 이전의 일부 작은 배열은 이미 제거되었을 수 있어 절감 바이트 수치를 주장하지 않는다. 메서드 병합 자체가 서버 전체 GC 개선을 보장하지 않는다.

전체 게임 의존성 타입 컴파일, 실제 MySQL·CacheD 장애 주입, 실제 게임 접속·아이템 사용 실험은 실시하지 않았다. 그 결과를 통과했다고 주장하지 않는다. NPC 38~65차의 기존 변경은 유지했지만, 이번 차수에서 NPC 관련 수정이나 추가 검증은 하지 않았다.

재현: `bash docs/item_only_phase66_20261118/run_tests.sh` (JDK 21 필요). 구문 파싱에는 별도 JavaCompiler 파서가 필요하며 위의 테스트는 전용 타입·실행 비교만 재현한다.
