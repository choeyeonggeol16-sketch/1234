# N7 — NPC 이동·버프·공성·경험치 분리

기준: RKern_NPC_Action_N6_Events_Experience_Receipt_FULL_SRC_20261119.zip

- CS_NpcAcion2의 32개 분기를 기존 NpcTravelCommands(17), NpcCastleActions(1), NpcGameEventActions(1), NpcExperienceCommands(1) 및 신규 NpcBuffCommands(12)로 이동. 기존 분기 순서를 유지한다. 두 50015 분기의 기존 첫 매칭 우선순위도 유지한다.
- 동일 NPC 템플릿 ID 재조회 제거, 훈련소 2~4 명령의 정규식 호출을 길이/문자 검사로 교체. 속죄의 성서 잘못된 명령에서 0개 소비 호출 생략(기존 consumeItem도 false 반환하므로 페이지는 동일).
- 낡은 고서, 클라우디아 주문서 지급의 null 반환 시 성공 안내 방지. 유리에 항아리 지급 null 반환 시 이름 참조 방지. 정상 지급량과 메시지는 유지.
- 버프 스킬 배열은 기존 정적 배열 그대로 이동. 새 스레드, 큐, 요청별 Context 없음. RNG 객체는 변경하지 않음.
- 아크프리패스 경험치 수식과 차감 정책은 그대로 유지. 경험치 영속 원자화는 미완료.

## 검증

- 32개 분기 원본 본문 대조(속죄의 성서 0개 호출 생략만 예외), 29개 이동·버프 함수 typed stub 원본/수정본 982,520개 조합 비교. 테스트의 시간 및 난수 seed는 고정; 실제 DB/게임이 아니다.
- 단일 BMP 문자 65,536개 정규식/문자 범위 대조, 3개 지급 null 가드 및 중복 route 순서 소스 검사.
- 기존 세실리아 15,616, 잘못된 보스 설정 8, 에킨스 11,520; 불골렘 13,833 및 유료 이동 30 모의 검증 통과.
- Java 21 구문 1,927개 오류 0. 같은 --release 21 --enable-preview 옵션으로 기준/수정 전체 타입 컴파일 시 기존 오류 531개/경고 5개, 진단 로그 byte-identical. 외부 의존성 부족 등으로 전체 빌드 성공은 아님.
- 전체 이전 아이템 회귀 스크립트, 실제 인게임/DB/Heap/JFR은 이번에 재실행하지 않음.

## 남은 작업

보스 훈련소 키 발급/맵 예약, 햄 퀘스트 진행도와 보상, 발라카스 입장, 오림 파티원 동시 차감 및 유료 이동, 불골렘 방어구 바닥 지급, XML 복합 제작 및 대화 세션. 이번에는 기존 동작과 실행 순서를 보존하기 위해 이 경로의 원자성을 변경하지 않았다. CS_NpcAcion2 완전 제거는 미완료. 중복 ID 50015의 도달 불가 분기는 운영 HTML 확인 전 활성화하지 않았다. 별도 CacheD·네트워크·NPC AI 코어 변경 없음.
