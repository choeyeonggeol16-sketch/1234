# N7 장비 교환 receipt 검수

기준: RKern_NPC_Action_N7_Veteran_Anton_Receipt_Audit_FULL_SRC_20261119.zip.
생산 수정: NpcExchangeCommands.java 한 개.
- 불골렘 A~P 방어구 제작의 기존 강화 수치, 재료 ID 및 수량 보존. 기존 receipt에 세 재료를 함께 차감하고 보상 이미지 등록.
- 비자야 A~D 키링크 교환: 비용/재료/보상 같은 receipt. 착용 장비 제외.
- 피어스 A~D 선택 목록: 기존 배열의 0~9 슬롯은 템플릿 ID가 아닌 객체 ID로 사용. 실제 선택 객체의 소유·강화·착용 상태 재검사. 보상 16~18 슬롯 계약 보존. 제출 성공 시 선택 초기화, 응답 지연으로 새 메뉴가 지워지지 않음. 롤백 후에는 메뉴 재선택 필요. 완전한 NPC 대화 세션 바인딩은 후속 작업.
- 세 거래 모두 지급 공간 부족 시 기존 바닥 지급 대신 전체 거부. 실제 DB 실패 및 ACK loss 실증은 미실시. CacheD/네트워크/공통 인벤토리 코어 변경 없음.

검증: 추출한 생산 메서드를 Java 21 typed mock으로 실행. 3,368개 시나리오, 150,304개 assertion 통과. 이전 베테르랑/안톤 211,450개 assertion 통과. 기존 피어스 테스트는 템플릿 ID/동기 지급 계약을 대상으로 하므로 이번 테스트로 해당 계약을 대체 검증. 모든 기존 회귀 전체 재실행은 하지 않음. Java 1,928개 구문 오류 없음. 전체 javac 실패(531 errors, 5 warnings), 직전 컴파일 진단 로그와 byte-identical. 실제 DB/인게임/heap 미검증.
