# 214~216차 아이템 도달성 및 재료 차감 검수

기준: 213차 최신 전체 SRC. 생산 Java 5개 수정, 추가/삭제 없음. 기존 비아이템 코드는 그대로 유지.

- 214: 70888(엘븐스트라이크)는 70731 학습 거래의 산출물이며, L1ItemInstance 설명 및 메인 디스패처에 존재하나 보조 레지스트리에서 먼저 소비되어 실제 효과에 도달하지 않는다. 보조 레지스트리에서 해당 ID만 제거하고 명시 TARGET 모드를 적용. 디스패처는 유효 실행만 COMPLETE를 반환한다. 실제 클라이언트의 targetId 전달/DB useType은 확인되지 않았다.
- 215: 엘븐스트라이크의 소유 아이템, 시전자 사망/텔레포트, 동일 맵, 대상 사망/투명/PC 텔레포트/유령/GM 은신을 검사한다. 공격/마법의 기존 PvP 규칙을 참고해 양쪽 안전지역/PvP 불가 상대를 차단하고, 몬스터/적대 펫·서먼·컴패니언만 NPC 대상으로 허용한다. 자신의 소환물, 숨은 NPC 및 비전투 NPC/문/타워는 제외한다. 기존 스킬 클래스/레벨/사거리/장애물/MP/대기시간/기본 확률/대미지/홀드 공식은 유지한다. 기존 L1PcInventory.tryConsumeCombatReagent로 재료 차감을 먼저 성공시킨 경우에만 MP/쿨다운/대미지/홀드를 실행한다. 실패 시 일반 완료 tail도 실행하지 않는다.
- 216: 매직실드(220012)에서 기존 재료 차감 결과 무시 및 버프 선적용을 수정. 동일 기존 짧은 인벤토리 gate를 사용하여 차감 성공 전 기존 버프 제거/새 버프/MP 변화를 금지하고, 실패 시 완료 tail을 건너뛴다. 기존 정상 조건/효과/소모량 유지. 두 public compatibility wrapper의 void 시그니처는 유지했다.

## 레지스트리 검수 결과
보조 registry-only ID 54개 중 70888 한 개를 정상 메인 경로로 전환. 나머지 53개는 그대로 유지. 그중 40개는 SupplementalItemActions에 있는 3000xxx ID에서 0 하나를 제거한 형태와 일치한다(300147 포함). 나머지 13개는 703,704,705,706,707,719,9995,300148,300211,300393,350198,3000148,3000393이다. 실제 운영 DB 및 역사적 배포 정책을 확인하기 전에는 삭제/리맵하지 않는다. 3000147 테베 이동은 지도 782 존재만 확인되고 이벤트 권한이나 아이템 DB가 미확인되어 계속 미활성화한다. 41019,41303,41304 기존 보조 우선순위 그대로 유지.

## 검증 범위
실제 수정 클래스 본문을 typed stub으로 Java 21 컴파일하고 registry 전수 범위, target decoder, PC/NPC 대상 및 차감 실패, 매직실드 조건 회귀를 수행했다. 198~203차 회귀 1298건 및 211~213차 기능 회귀 98건 재실행. 전체 생산 Java 1913개 구문 오류 0. 실제 게임 전체 타입 컴파일, 동시 전투, MySQL/CacheD 재시작/ACK 유실, 운영 아이템 DB 검증은 미실시. combat reagent gate는 기존 동기 인벤토리 변경 보호이며 DB ACK 원자 커밋을 새로 보장하지 않는다. 새 클래스/스레드/큐/패킷 구조는 추가하지 않았다.
