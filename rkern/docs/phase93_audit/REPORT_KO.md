검수 기준: `RKern_NC_NativeBroadcast_Phase92_Global_FailureAudit_FULL_SRC_20261117.zip`

## 확인한 범위

- 이전 84~92차의 변경 파일 이력과 최신 92차 코드, 전체 Java 1,710개 구문을 정적 점검.
- 방송 코어의 단일 immutable Native source, 첫 수신자 실패, 중간 수신자 실패, 두 그룹 FIFO, 자기 자신·필터 처리, 참조수 반환 경계 재검증.
- 오림/발라카스/글루디오 인던/전투장/혈맹/수성/11층 지배의 탑/NPC 스폰/오브젝트 제거/펫 및 일부 스킬 이펙트의 선택적 알림 실패가 게임 상태 처리를 중단시키는지 추적.
- 기존 87~92차 테스트 재실행 + 93차 신규 테스트 (`run_tests.sh`).

## 새로 확인하여 수정한 오류·위험

1. **수신자 단위 실패 격리 오류:** 이전 `sendWritten*BestEffort`가 안쪽 strict 루프를 한 번에 호출하여 첫 수신자 SEND 예외 시 그 뒤 수신자를 건너뛰는 문제. 한 수신자의 실패 후에도 원래 순서를 따라 후속 수신자에게 동일한 Native 원본을 전달하도록 변경. 배열/리스트/레드·블루 두 그룹/전서버 플레이어/GM 필터 경로 검사.
2. **첫 수신자 Native 참조 누락:** strict `sendWrittenTo`가 처음 만든 원본을 호출자에게 돌려주기 전 예외를 던지면 해당 래퍼의 `close`가 호출되지 않을 수 있는 문제. 초기 source 생성 직후 실패 시 즉시 반환하고 원래 예외는 유지, `release` 예외는 suppressed 처리. 생산 코어 기반 모의 테스트로 재현/검증.
3. **게임 진행 중단 위험:** 발라카스 레이드 READY, 메테오와 광역 피해, 오림 점수/횟수, 글루디오 인던 시작·종료, LFC 및 전투장/경기 종료·보상, 혈맹 해산/탈퇴 및 만료 버프, 수성 방어권 이전·지배의 탑/보스 스폰, 게임 오브젝트 제거·인식목록 반환 등의 선택적 방송 실패를 게임 상태 처리와 분리. 정상 송신/수신자 순서 보존.
4. **비선택적 중요 작업 분리:** 사망 페널티 아이템 처리 뒤 GM 알림 예외가 아이템 로그 갱신을 끊는 경계, 혈맹 탈퇴 COMMIT 후 알림 실패, 파티 시각 효과 실패가 HP·죽음 흐름에 전파되는 경계를 정리.
5. **검증 및 오류 분류:** 실제로 값이 다른 수신자별 패킷/DB 확정 작업은 임의로 공유하지 않음. 독립된 게임 비즈니스 오류를 방송 예외로 숨기지 않도록 기존 strict 전송 함수는 유지하고, 시각/공통 공지 전송만 best-effort 경로로 분리.
