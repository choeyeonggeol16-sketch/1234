# RKern 아이템 37차 — NPC 봉인·강화 지급 실패 경계

`CS_NpcAcion2.java`의 `봉인템`, `인첸트지급` 두 메서드를 검수했다.

- `ItemTable.createItem`이 사전 등록한 월드 객체를 인벤토리 거절·병합·예외 시 회수한다.
- `storeItem`이 null을 반환하면 허위 지급 성공 메시지를 보내지 않는다.
- 봉인 장비의 축복 변경/저장 대상은 실제로 인벤토리에 들어간 `stored` 인스턴스로 맞춘다. 특히 스택 병합과 같은 경계에서 임시 객체를 업데이트하지 않는다.
- 기존 아이템 ID, 강화 수치, 반환/메시지 성공 경로를 유지한다. 트랜잭션 시스템 자체는 수정하지 않는다.

Java 21 실제 메서드 추출 타입 컴파일과 인벤토리 mock 원본 비교: `bash docs/item_domain_phase37_20261118/run_tests.sh`. 전체 서버 컴파일·실DB 장애 검증은 별도.
