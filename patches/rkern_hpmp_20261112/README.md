## 수정 내용과 선택한 정책

- **HPMP-01:** 최대 HP/MP의 25/35/45 누적 +50/+100/+150은 생성 당시 `getBaseCon/Wis()`나 장비 포함 `getTotalCon/Wis()` 대신, 레벨업·엘릭서 영구 배분을 포함한 `getCon/Wis()`로 판정합니다. 다른 장비/버프의 직접 HP/MP 가산은 보존합니다. 최대값을 설정할 때도 영구 스탯 보너스를 포함한 상한으로 현재 HP/MP를 제한합니다. NPC의 기존 MP 보너스 규칙은 유지합니다.
- **HPMP-02:** 실제 HP 레벨업은 표시용 `PureHp`와 같은 원천에 0/1 주사위만 더합니다. CON12의 최소값은 군주12·기사17·요정10·마법사7·다크엘프11·용기사13·환술사9·전사17입니다. 기존 캐릭터의 누적 기본 HP는 재계산하지 않습니다.
- **HPMP-03:** MP 증가와 표시 범위를 같은 클래스별 식으로 통일했습니다. 최소는 `floor(floor(WIS/5)*클래스계수)+클래스가산`, 최대는 분모를 3으로 바꾼 값이며 그 범위에서 기존 방식의 균등 정수 추첨을 합니다. 계수는 군주1, 기사/전사2/3, 요정/다크엘프3/2, 마법사2, 용기사7/10, 환술사17/10입니다. 실제 성장과 라이브 표시 모두 순수 WIS를 사용하며 배분 미리보기는 제시된 스탯으로 계산합니다. 연구 시트로 대조한 범위는 WIS1~45이고 그 위는 같은 식의 확장입니다.
- **생성·초기화 기준:** 서버가 원래 사용하던 클래스별 생성 HP/MP를 공통 함수로 옮겨 생성과 스탯 초기화가 같이 참조합니다. 생성 캐릭터의 레벨도 1로 명시합니다. 기존 생성 MP의 WIS별 차이는 유지하며 연구 시트의 고정 초기 MP로 기존 캐릭터나 생성 규칙을 일괄 교체하지 않습니다.
- **HPMP-04:** 기본 MP 자연회복을 `max(1, floor(totalWIS/5)+floor(level/40)+순수WIS보너스)`로 통일했습니다. 순수 WIS 보너스는 25/35/45 이상에서 각각 총1/2/5입니다. 별도 WIS 기본 회복과 `엠회복틱()`을 중복 합산하던 경로를 제거하여 80레벨 WIS20 무보정 회복은 6입니다. 장비·물약·버프·지역 회복은 별도 성분으로 유지합니다. HP의 랜덤 기본 회복과 고정 CON 성분은 동일 항목의 중복이라는 근거가 확인되지 않아 임의 삭제하지 않았고, 고정 성분은 현재 순수 CON을 사용하도록 했습니다.
- **HPMP-05:** 정상 자연회복량을 계산한 뒤 무게 초과 시 순수 CON45 이상은 HP만, 순수 WIS45 이상은 MP만 절반 회복합니다. 임시 스탯으로 45를 넘겨도 열리지 않습니다. 홀수 절반은 정수 내림을 채택한 구현 정책이며 공식 확정 실측이라고 주장하지 않습니다. 허기·버서커·배리어·기존 무게 예외 버프, 회복 주기, 환경 피해, 인형/장비의 별도 발동은 유지합니다.
- **HPMP-06:** 실제 획득한 레벨별 HP/MP 증분을 `hp_mp_growth`에 저장합니다. 레벨다운은 해당 확정 증분을 제거하고 재레벨업은 같은 증분을 복원하므로 반복 추첨으로 수치가 떠다니지 않습니다. 상한에 막힌 경우에는 실제 반영된 증분만 기록합니다. 스탯 초기화는 임시 이력에 새 증분을 쌓고 최종 검증 후 교체하며, 진행 중 자동 저장을 막습니다. 기존 short 덧셈이 먼저 넘치던 기본 HP 증가도 int 계산 후 제한하도록 고쳤습니다.
- **저장 경계:** 기존 캐릭터 잠금으로 EXP·레벨·성장·총량 전이와 스냅샷을 보호합니다. `addExp`의 기존 PC 모니터와 사용자 잠금이 역순으로 맞물리지 않도록 같은 사용자 잠금 순서로 통일했습니다. 신규 워커·큐·테이블을 추가하지 않았고 기존 CacheD 스냅샷/캐릭터 UPDATE에 성장 이력 문자열을 포함했습니다. 기존 저장 HP/MP는 순수 스탯을 복원한 뒤 제한하며 현재 HP/MP 읽기도 int로 바꿔 순수 보너스까지 포함한 값이 short에서 잘리지 않도록 했습니다.

**과거 이력이 없는 캐릭터:** 적용 이전 획득량을 임의로 만들 수 없으므로 최초 추적 레벨을 기준점으로 둡니다. 그 아래로 내려갈 때 기존 누적 HP/MP를 보존하고, 같은 옛 레벨을 다시 올릴 때 추가 성장도 지급하지 않습니다. 기준점 위에서 새로 기록한 구간은 정확히 되돌립니다. 정식 스탯 초기화를 끝내면 레벨1부터 새 이력이 생깁니다. 이는 기존 데이터를 보존하는 호환 정책이며, 과거 모든 레벨업을 복원했다는 뜻이 아닙니다.

저장된 기본 HP/MP를 일괄 보정하지 않지만 **장비로 잘못 열리던 순수 스탯 보너스가 닫히므로 표시 최대값은 수정된 판정에 따라 달라질 수 있습니다.** 기록된 옛 레벨은 영구 스탯이 바뀌어도 기존 증분을 복원하고, 처음 도달하는 새 레벨은 그때의 순수 스탯을 사용합니다. 재분배에 맞춘 전체 재성장은 정식 초기화 절차에서 처리합니다.
