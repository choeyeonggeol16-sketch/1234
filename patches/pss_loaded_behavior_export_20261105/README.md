# PSS 실행 중인 행동 목록 내보내기

`playSupport.json` 파일을 찾거나 클라이언트 데이터 묶음을 직접 풀지 않고, **실행 중인 게임이 이미 구성한 Battle 행동 목록**을 읽는다. 결과는 원본 JSON 파일이 아니라 현재 로드된 구조를 표현한 진단 보고서다.

1. 게임에 들어가 PSS를 시작하고, 몹이 없어 가만히 서 있는 상태로 둔다.
2. 이 ZIP을 별도 폴더에 풀고 **`PSS_Loaded_Behavior_Export.cmd`**를 실행한다.
3. 바탕화면에 생성된 **`PSS_Loaded_Behavior_날짜시간.json`**을 보낸다.

PID 입력이나 파일 선택은 없다. PSS 설정창과 서버, DLL을 다시 설치하거나 Apply를 실행하지 않는다. 게임과 같은 권한으로 실행한다.

이 도구는 **읽기 전용**이다. 게임 함수 호출, 패킷 전송, 게임 파일·메모리 변경을 하지 않는다. 이미 확인된 클라이언트 해시 2개와 월드 진입·PSS 타입 정보를 확인한 뒤 해당 Battle 루트에서 연결된 노드만 읽는다. 노드의 타입, 내부 태그, 자식 순서와 진단 상태를 기록한다. 계정·비밀번호·채팅·인벤토리나 전체 프로세스 메모리는 수집하지 않는다. 사용자의 PC 경로는 보고서에 넣지 않는다.

Sequence/Selector의 자식 목록은 확인한 함수표와 연결 리스트 구조를 사용한다. Inverter는 MSVC 타입 메타데이터로 확인된 경우만 읽는다. 미확인 타입은 구조를 추측하지 않고 경고를 남긴다. 순환 참조, 자식 수, 깊이, 노드 수와 읽기량에 상한이 있다. 최대 프로세스 3개, 프로세스당 그래프 256노드·깊이 24·자식 64개·그래프 읽기 256KiB다. 결과는 실행 중 한 순간의 비원자적 스냅샷이며, 중간에 PSS 작업이 바뀌거나 목록이 변경되면 경고를 남긴다.

검증: C# 컴파일, C#/PowerShell 구문, 가상 메모리 자료를 이용한 동작·상한 검사 17개를 통과했다. 실제 게임에서 이 도구의 수집은 아직 확인하지 않았다. 이 배포물은 배회 수정 패치가 아니다. 기존 자료에서 확인되지 않은 자식 작업 연결을 읽기 위한 도구다.
