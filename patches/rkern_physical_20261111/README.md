## 변경 동작

1. **SOF 최대 다이스:** 버프가 있고 실제 무기를 든 근접 물리 공격에만 적용합니다. 기존 원거리 조건 역전을 바로잡았으며 활·건틀릿·맨손은 SOF로 최대 다이스를 얻지 않습니다. 키링크는 기존 별도 마법 계산을 유지합니다.
2. **고정 DR 뒤 버닝 계열 배율:** 공격 계산에서 1.5배를 미리 적용하지 않고, 대상의 기본 고정 DR을 차감한 뒤 적용합니다. `D=100, DR=10`이면 `floor(90*1.5)=135`입니다. PC의 REDUCTION_ARMOR/MAJESTY/DRAGON_SKIN, ARMOR_GUARD, 방어구·인형 고정 DR 단계 뒤에 배율을 넣고, 이뮨 퍼센트 방어는 그 뒤에 유지합니다. NPC는 기존 NPC 고정 DR 뒤에 적용합니다.
3. **퓨리 피해 방식:** 크래시 추가타를 두 번 더하던 코드를 제거하고, 크래시를 포함한 해당 물리 공격 결과를 고정 DR 뒤에 2배 합니다. `기본100+크래시40, DR10`이면 `130*2=260`입니다. 버닝과 함께 발동하면 1.5배 내림 후 2배 순서입니다. 발동 플래그는 매 계산에서 초기화해 재계산 시 이전 퓨리가 남지 않도록 했습니다.
4. **크로우 치명타 확률:** 캐릭터 확률 `pc`, 무기 확률 `pw`를 `pc+pw-pc*pw`의 독립 합집합으로 결합합니다. 0.01% 단위 정수 확률로 **한 번만 추첨**하므로 10%+25%는 정확히 32.5%입니다. 다른 무기의 기존 치명타 추첨은 유지합니다.
5. **손상 무기의 무기 부분 하한 1:** 실제 무기가 있는 일반 물리 공격에서 `주사위+고유추타+강화+언데드보너스-손상` 부분만 최소 1로 만듭니다. 속성·캐릭터 추가타격은 그 뒤에 붙이고, 맨손의 기존 최소 0 및 키링크 별도 계산은 유지합니다. 더블브레이크/이도 더블 연산 순서는 그대로입니다.

**DR 범위:** 모든 감소를 일괄 앞당긴 수정은 아닙니다. 기존 아바타·트루타겟·아머브레이크 및 PvP 보정 단계는 유지하고, 위에 명시한 고정 DR과 최종 배율의 경계를 조정했습니다. 피격 PC의 기존 GotDamage에서 처리하는 PvP 기본 감면·루시퍼·방어구 발동과 마법인형의 후속 발동 위치도 유지합니다. DR로 막힌 0 이하 피해를 배율로 다시 살리지 않으며 새 배율의 int 초과는 포화 처리합니다.

**확률 제외 범위:** 더블브레이크(두 오버로드), 이도 무기 더블, 크래시·퓨리 발동 추첨 메서드는 기존 소스와 동일합니다. `AttackSkillChanceConfig.java` 전체와 운영 설정도 바꾸지 않았습니다. 테스트에서만 발동률을 해당 JVM 내부에서 100%로 고정하여 발동한 타격의 수치를 비교합니다. 운영 확률을 100%로 변경하는 패치는 아닙니다.
