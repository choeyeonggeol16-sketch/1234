# PSS 이동 코드 추가 확인 V2

첫 ZIP은 정상적으로 분석했다. PSS 실행 플래그가 1이며, 작업 완료를 검사하고 전투 큐를 다시 구성하는 루프가 살아 있는 것을 확인했다. 다만 그 루프가 호출하는 실제 작업 본문 3개가 첫 도구의 수집 범위 밖에 있었다. 이번 도구는 **확인된 그 코드 영역과 현재 대기 중인 PSS 작업 이름**을 추가로 읽는다.

1. 게임에서 PSS를 시작한 뒤 **몹이 없어 가만히 서 있는 상태**로 둔다.
2. 이 ZIP을 별도 폴더에 풀고 **`PSS_Roaming_Code_Check.cmd`**를 한 번 실행한다.
3. 바탕화면의 새 **`PSS_Roaming_Code_날짜시간.zip`**을 올린다. 보고서 첫 줄에 **V2**가 표시된다.

PID나 파일 선택 입력은 없다. 게임과 같은 권한으로 실행한다. 서버·클라이언트·DLL을 교체하거나 패치를 다시 적용할 필요가 없다.

읽기 전용이며 패킷 전송이나 게임 함수 호출, 게임 파일/메모리 변경을 하지 않는다. 실행 코드의 범위는 프로세스당 최대 96페이지(384KiB)로 유지한다. 별도로 고정된 PSS 작업 이름·함수표 최대 8KiB와 PSS 내부 실행 상태, 현재 작업의 짧은 영문 이름만 읽는다. 전체 메모리, 계정·비밀번호·채팅·인벤토리는 수집하지 않는다.

첫 도구가 기록한 `flow`는 실제 작업 객체가 아니라 활성 큐를 가리키는 값이었다. 실제 디스어셈블 결과에 맞춰 현재 작업 포인터와 이름을 읽도록 보완했다. **현재 자료만으로 배회 함수나 원인을 확정하지 않았고, 게임 동작을 바꾸는 도구가 아니다.**
