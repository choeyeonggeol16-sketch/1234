# ATS V9 — 창 밖 클릭·비활성화 중단 수정 / 아이콘과 시간 분리

V7/V8 서버와 DLL을 함께 갱신하는 버전입니다. **서버 Java 2개를 반영하고 재빌드해야 합니다.** V7 DB를 사용 중이면 SQL 추가 변경은 없습니다.

![V9 HUD 미리보기](preview/hud-v9.gif)

위 화면은 동일 HUD 소스를 Wine64에서 실행한 미리보기입니다. 게임 화면이 아니며, 한국어는 Noto Serif CJK KR 대체 글꼴입니다. 원본 참고 이미지와 완전히 동일한 픽셀/글꼴 복제를 보장하지 않습니다.

## 적용

1. 자동사냥을 끄고 서버와 게임을 종료합니다. 기존 파일을 백업합니다.
2. 서버 소스를 아래 2개로 갱신하고 프로젝트의 기존 빌드 방식으로 재빌드합니다.
   - `src/l1j/server/AutoHuntSystem/NativeStepSession.java`
   - `src/l1j/server/AutoHuntSystem/AutoHuntController.java` (기존 CP949 인코딩 유지)
3. `client-ready/dinput.dll`과 `client-ready/ats_bg.png`를 Mega.bin 옆에 복사합니다.
4. `ats_hud.ini`에 `ShowSeconds=0`과 `TextScalePercent=90`을 반영합니다. 이미 조정한 `Bottom`, `OffsetX`, `ScalePercent`는 보존해도 됩니다. 새 설치는 동봉 INI를 사용합니다.
5. 서버와 게임을 켜고 기존 49027 아이템으로 시작합니다. DLL 로그에서 `native-tile-input-v9-focus-silent-20261111`을 확인합니다.

패치 ZIP은 위 서버 2개와 클라이언트 완성 파일, 네이티브 소스/검사, 적용 문서를 포함합니다. 전체 소스 ZIP에는 V7 이용시간 시스템과 DB 스크립트까지 모두 포함됩니다.
V6 이하에서 처음 설치하는 경우에는 **전체 소스**의 `ATS_V7_APPLY_KO.md`에 따라 V7 서버 변경과 `db/ATS_V7.sql`부터 반영하세요. V9의 서버 2개만으로 V7 기능을 새로 설치할 수 없습니다.

## 중단 관련 변경

- 기존 DLL은 게임이 앞 창이 아니거나 전역 왼쪽 버튼이 눌리면 자동사냥을 종료했습니다. 포커스 상실만으로 종료하는 경로를 제거했습니다.
- 물리 클릭이 시작된 위치를 구분합니다. 게임 밖·다른 창·제목 표시줄 클릭, 밖에서 누른 채 안으로 끌기, 비활성 게임을 다시 선택하는 클릭은 수동 중단으로 취급하지 않습니다.
- 이미 활성화된 게임의 클라이언트 영역을 직접 클릭하면 기존처럼 수동 중단합니다. 아이템 시작 클릭의 버튼이 풀리기 전 입력하지 않는 보호도 유지합니다.
- 네이티브 입력 준비가 안 된 순간에는 승인 시간 내에서 기다립니다. DOWN 직전의 좌표/목표 검사는 유지합니다.
- 서버가 이동 패킷을 한 번도 받지 못한 채 같은 원점에서 2회 재시도까지 소진하면, 대기 간격 후 그 경로만 버리고 다시 계획합니다. 무응답만으로 전체 자사를 종료하지 않습니다. 실제 원점 변경·잘못된 방향·승인 후 미적용은 계속 재동기화 대상으로 처리합니다.
- 다른 앱으로 커서를 옮기거나 게임 포커스를 강제로 가져오는 처리는 없습니다.

HUD는 다른 앱 위를 가리지 않도록 게임이 뒤에 있을 때 숨기고 돌아오면 표시합니다. HUD 숨김은 자동사냥 종료와 별개입니다. 최소화 상태의 실제 게임 동작은 확인하지 않았습니다.

## 아이콘과 남은 시간

사용자가 올린 이미지는 ATS 아이콘만 담고 있습니다. 남은 시간은 PNG 안의 고정 문자가 아니라 **서버의 잔여 시간을 받아 DLL이 그리는 글자**입니다.

- 링 안은 비우고 ATS 글자를 링 아래로 이동했습니다.
- 원 위 화살표는 회전하고 ATS 글자는 고정됩니다.
- 그 아래에 작은 글씨로 `남은시간: 19시간 33분`처럼 표시합니다.
- `ShowSeconds=0`은 시간·분만 표시합니다. 내부 초 단위 계산과 차감은 계속됩니다. 초 표시를 원하면 `1`로 바꿉니다.
- `TextScalePercent=90`은 시간 글씨만 축소합니다. 이용시간 잔액을 줄이는 설정이 아닙니다.

```ini
[ATS]
Enabled=1
Bottom=124
OffsetX=0
ScalePercent=100
ShowSeconds=0
FontFace=Batang
TextScalePercent=90
```

`ats_bg.png`는 붉은 바탕만 포함하며, 링·ATS·시간은 DLL에서 별도로 그립니다. 동봉 `ATS_Preview.exe`는 게임 없이 표시를 확인하는 도구입니다. Space 정지/재개, Esc 종료이며 미리보기 시간은 게임 DB와 무관합니다.

실제 이용시간은 V7 그대로입니다. 자사 중에만 차감하고 정상 종료 시 남은 시간을 보존합니다. 레벨·맵 조건은 `config/autohunt_ats.properties`, 잔액은 `character_ats_time`입니다. 초기 24시간은 캐릭터 최초 이용 때 한 번 지급하며 일일 초기화는 없습니다. 강제 종료·환급 실패 시 예약된 미사용분 최대 약 10초가 추가 차감될 수 있습니다.

## 검증 범위

- 배포용 x86 PE32 DLL/미리보기 및 검사 실행 파일 빌드 통과.
- 외부 클릭·끌기·재활성화·제목 표시줄·게임 안 수동 클릭·시작 클릭 해제 단위 검사 통과.
- 이동 코어 10,000회, 시간 상태 검사를 ASan/UBSan으로 실행해 통과.
- 실제 `nativestep_dll.cpp`의 Win32 훅·타이머·메시지 루프를 Wine64의 두 창으로 실행했습니다. 게임 창을 뒤에 둔 한 걸음, 포커스/OS 커서 유지, 다른 창에 클릭 메시지 없음, 준비 안 된 입력의 만료 및 다음 승인 재개를 확인했습니다. **이 검사에서 게임 메모리 함수·네트워크·HUD는 가짜 구현이며 실제 Mega.bin 백그라운드 이동 검증은 아닙니다.**
- 실제 Java NativeStepSession의 무응답/재시도/대기/같은 원점/승인된 이동 회귀 검사와 ATS 잔액·조건 검사를 통과했습니다.
- 컨트롤러 Java 구문 파싱 통과. 전체 서버 의존성 연결 빌드, 실제 MySQL, 새 DLL을 넣은 Windows 실게임, 독점 전체 화면은 미검증입니다.

검증 로그와 V8 대비 소스 변경은 `validation/`에 있습니다. 이전 검증 기록은 `historical-v8/validation/`에 보존했습니다.
