# PSS 행동 정의·설정 확인 V3

V2 자료는 정상 수집됐으며 현재 작업이 `Battle`임을 확인했다. 전투 관리 코드가 실제 행동을 구성할 때 클라이언트 데이터 파일을 읽고, V2 범위 다음인 `0x0068xxxx`의 노드 구현도 생성한다. 앞선 도구가 관리 코드 위주여서 이 부분과 실행 설정을 담지 못했다. 이번 도구는 **참조 파일명, 고정 노드 이름/함수표, 관련 노드 코드, 실제 Battle 설정의 분기 바이트와 타겟 상태**를 함께 읽는다.

1. PSS를 켠 상태에서 몹이 없어 서 있을 때 실행한다.
2. 별도 폴더에 압축을 풀고 `PSS_Roaming_Code_Check.cmd`를 한 번 실행한다.
3. 바탕화면에 생성된 새 `PSS_Roaming_Code_날짜시간.zip`을 보낸다. 보고서 첫 줄에 **V3**가 표시된다.

PID 입력이나 서버/DLL 교체, Apply 재실행은 필요 없다. 이 도구는 게임과 같은 권한으로 실행한다.

읽기 전용이다. 게임 파일·메모리 변경, 게임 함수 호출, 패킷 전송은 하지 않는다. 정확한 두 SHA-256의 클라이언트만 대상으로 하며, 월드 진입 및 알려진 PSS 코드 확인 후 수집한다. 실행 코드는 프로세스당 최대 96페이지(384KiB), 고정 문자열·함수표는 최대 64KiB이며 최대 3개 프로세스까지만 처리한다. 별도로 PSS 실행 상태와 확인된 설정 바이트, 현재 타겟 번호·PSS 기준 좌표·경로 인덱스만 기록한다. 전체 메모리, 계정·비밀번호·채팅·인벤토리, 사용자 설정 문자열은 수집하지 않는다.

이 도구는 배회 수정 패치가 아니다. `Battle` 작업이나 큐 개수만 보고 원인을 단정하지 않고, 실제 타겟 없음 분기와 행동 정의를 대조하기 위한 자료다. 수집 상태는 한 순간의 참고값이며, 동시 실행 중 설정이나 작업이 바뀔 수 있다.
